Releases 12.1
=============

Release 12.1.0
==============

We are happy to announce new major version 12.1 of EXT:tika for TYPO3 13 LTS.
This is security release including support Apache Tika v. 3.2.3+ and Solr v. 9.10.1+

.. note::

      All Apache Tika prior v 3.2.2 and Solr prior 9.10.1 are vulnerable
      against `CVE-2025-66516 / CVE-2025-54988 <https://solr.apache.org/security.html#cve-2025-66516-apache-solr-extraction-module-vulnerable-to-xxe-attacks-via-xfa-content-in-pdfs>`_
      please update the applications or apply fixes manually and set
      :php:`$GLOBALS['TYPO3_CONF_VARS']['EXTENSIONS']['tika']['skipSecurityChecks'] = true` on your own risk.
      EXT:tika will silently stop work on insecure versions.

!!! [FEATURE] Support Apache Tika 3.2.3+ and Solr 9.10.1+ versions only
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

This change addresses the CVE-2025-66516 and updates the Tika Server/App to v. 3.2.3+.
Due of CVE-2025-66516 / CVE-2025-54988, we are droping support for Tika <3.2.2 and Apache Solr <9.10.1.
See the note on top.
